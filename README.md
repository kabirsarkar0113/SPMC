# Shakipio Massage Company

A responsive massage booking website built with HTML, CSS, and JavaScript.

## Massage V1

**File:** [`Massage.html`](Massage.html)

- Select up to two of seven massage types.
- Choose 2–14 minutes.
- Calculate prices at ₹5 per minute, per massage.
- Confirm bookings and view transaction history.
- Save bookings in `localStorage`.
- Clear history through Pay when revenue exceeds ₹100.

## Massage V2

**File:** [`Massage_v2.html`](Massage_v2.html)

- Improves the V1 booking flow.
- Uses 2–7 minutes and a ₹6-per-minute rate.
- Shows total duration and combined pricing.
- Saves transaction history in `localStorage`.
- Creates permanent payment receipts after Pay.
- Keeps past receipts even when active history is cleared.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Browser `localStorage`
